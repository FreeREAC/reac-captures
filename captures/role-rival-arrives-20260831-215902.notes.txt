## Measured from this capture, 2026-08-31

**The condition:** the S-4000S (00:40:ab:c4:08:bc) had its REAC Mode switch on **M**. The
operator set it there by hand — this is the founding incident reproduced DELIBERATELY, the first
time a box mastering the wire has been recorded on purpose.

**What the console published while this ran** (`/reac/segment/default`):

    masterState  foreign
    rivalKind    unknown        <-- NOT `box`
    refusal      rival-master-unknown

**What the daemon logged:**

    reac-master: still PROBING: box present, not joining — bounce the box PHY

**Frame census over 200 000 frames** (source -> dest : length):

Both 1204 and 1206 are AUDIO frames (a leading counter, then repeating sample words) — the split
is a small trailer variance, not two geometries. **The box does NOT masquerade as a desk**: it
keeps its own 32-channel width while mastering. An early reading of this capture claimed
otherwise and was wrong; the 1492s are ours.

## THE FINDING, and it is a defect in §2b's premise

§2b rules that a rival master is classified BY ITS GEOMETRY, so that a desk can be joined and a
stagebox-on-M can be refused with the remedy that names the switch. **On this capture that
classification does not fire**: the box keeps its 32-channel geometry, which should read `box`,
and `rivalKind` still reads `unknown`. The operator therefore gets the generic
`rival-master-unknown` refusal instead of "set the REAC Mode switch to S and power-cycle".

Not yet root-caused. Two candidates, and the capture can settle it:
  1. the classifier reads geometry only from CONTROL frames (`cdea`/`cfea` families) and this box
     emits none while mastering, so it never gets a width to judge;
  2. it does emit them and the width parse rejects them for another reason.

`reac-disco` logging `model=unknown` alongside `master` points at (1).

**This is exactly the knowledge §8a was blocked on.** Before a role can be a settable field, the
console has to be able to say WHAT it is refusing, and today it cannot tell a box on M from an
unidentifiable master.
